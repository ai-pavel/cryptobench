🗄️ Storage Key

Build the raw storage key for a pallet's storage item and its map keys, or split an existing key back into its parts.

Split a storage key

Key = Twox128(pallet) ‖ Twox128(item) ‖ hasher(SCALE(key)) for each map key. Only the Blake2_128Concat, Twox64Concat and Identity hashers keep the key readable, so only those can be split back.
