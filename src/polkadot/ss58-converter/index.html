🔄 SS58 Converter

Convert an address between network prefixes. The same account has a different address on Polkadot, Kusama, Bittensor and other Substrate chains.

An SS58 address is Base58 of: network prefix (1 byte below 64, otherwise 2 bytes) + the 32-byte account id + a checksum, the first 2 bytes of Blake2b-512("SS58PRE" ‖ prefix ‖ account id). Moonbeam and other Ethereum-style chains use 20-byte H160 accounts instead, so their addresses can't be converted this way.
