✍️ Sign & Verify

Sign a message with an Sr25519, Ed25519 or ECDSA key, or check a signature the way Polkadot.js signatureVerify does.

Runs locally in your browser. Don't paste keys that hold real funds. The dev phrase above is public.

Wallets (Polkadot.js, Talisman, SubWallet) wrap messages in <Bytes>…</Bytes> before signing, so a signed message can never be a valid transaction. Sr25519 signatures include randomness, so signing the same message twice gives different signatures; both are valid. ECDSA signs the Blake2b-256 hash of the message and appends a recovery byte (65 bytes).

Tries Sr25519, Ed25519 and ECDSA, with and without the <Bytes> wrapper, and accepts signatures that start with a MultiSignature type byte (00 Ed25519, 01 Sr25519, 02 ECDSA).
