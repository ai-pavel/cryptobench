Address types

All base addresses of one wallet account share one stake address: it's where staking rewards go and what gets delegated to a pool.

The first byte of a Shelley address holds the type (high 4 bits) and the network (low 4 bits: 1 = mainnet, 0 = testnets). Base addresses carry a payment and a stake credential. Enterprise addresses have no stake part. Pointer addresses point at the certificate that registered a stake key. Reward (stake) addresses hold only the stake credential. A credential is the Blake2b-224 hash of either a public key or a script.

Byron addresses (Ae2…, DdzFF…) come from Cardano's first era: base58 over CBOR with a CRC32 checksum.
