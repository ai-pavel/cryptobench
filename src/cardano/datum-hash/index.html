#️⃣ Datum Hash

Compute the hash of a Plutus datum, as used in transaction outputs and by smart contracts.

Why the same datum can have different hashes

The hash is Blake2b-256 of the datum's exact CBOR bytes. CBOR allows several encodings of the same value (definite or indefinite-length lists, chunked byte strings), and each gives a different hash. When you paste CBOR, the tool hashes those bytes as they are. When you paste JSON, it encodes it the way cardano-cli and the Haskell node do: indefinite-length lists, byte strings longer than 64 bytes split into 64-byte chunks, and big integers as CBOR bignums.
