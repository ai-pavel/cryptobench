💰 Unit Converter

Convert between a base denom (like uatom) and its display unit (ATOM), exactly.

How it works

Cosmos SDK chains store amounts as integers in a base denom. The display unit is the base amount divided by 10exponent. Most chains use 6 decimals (1 ATOM = 1,000,000 uatom); EVM-compatible chains such as Injective, Evmos and dYdX use 18. The math here uses exact big integers, so nothing is rounded.
