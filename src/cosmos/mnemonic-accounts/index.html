🌱 Mnemonic Accounts

Generate or check a BIP39 mnemonic and derive Cosmos accounts from it (m/44'/118'/0'/0/i by default).

How it works

The mnemonic and passphrase give a 64-byte seed (BIP39). Keys are derived along m/44'/coin'/account'/0/index (BIP32/BIP44). With coin type 118 the address is RIPEMD-160(SHA-256(compressed public key)); with coin type 60 it is the Ethereum-style Keccak-256 address, as used by Injective and Evmos. Keplr, Leap and the SDK CLI use account 0 and change 0 and vary the last index.
