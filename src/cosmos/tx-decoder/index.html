📦 Transaction Decoder

Decode a signed Cosmos SDK transaction (TxRaw protobuf): messages, fee, signers and the transaction hash.

How it works

A broadcast transaction is a protobuf TxRaw: the encoded body (messages, memo, timeout), the encoded auth info (signers, fee) and the signatures. Each message is an Any — a type URL plus bytes. Common bank, staking, distribution, governance, IBC transfer, authz, CosmWasm and fee-grant messages are decoded by name; others are shown as a schema-less field tree. The transaction hash is the uppercase hex SHA-256 of the exact bytes.

Signer addresses are derived from the public keys, using the address prefix found in the messages.
