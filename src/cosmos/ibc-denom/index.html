#️⃣ IBC Denom

Turn an IBC denom trace into its ibc/… hash, or look up a well-known hash.

Multi-hop traces work too, e.g. transfer/channel-141/transfer/channel-0/uatom.

Well-known IBC denoms

How it works

When a token travels over IBC, the receiving chain records its path ("port/channel" for every hop) plus the original base denom, and names the voucher ibc/ + uppercase hex SHA-256 of that full trace. Hashing only works one way: getting the trace from a hash needs the chain's denom_traces query, which this offline tool can't make — but well-known hashes are listed above.
