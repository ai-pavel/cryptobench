🆔 Object ID

Derive object IDs: objects created by a transaction, dynamic fields and derived objects.

Every new object’s ID is BLAKE2b-256(0xf1 ‖ transaction digest ‖ index as u64 little-endian). The index counts IDs created by the transaction from 0, in creation order (including objects deleted again in the same transaction).
