🔢 Op Code

Compute a message op code from its TL-B constructor, the way TON contracts derive them.

How it works

The scheme is normalized: an explicit tag (#… or $…) and brackets are removed, a trailing ; is dropped and whitespace is collapsed. The op code is the CRC32 of that text with the highest bit cleared.

Some standard ops use the same CRC32 with the highest bit set instead, often responses such as excesses (0xd53276db). Both forms are shown.
