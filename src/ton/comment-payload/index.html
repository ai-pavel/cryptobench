💬 Comment Payload

Build the message body for a text comment, or read the comment from a body BOC.

Format

A text comment is a cell that starts with the 32-bit op code 0, followed by the UTF-8 text. Text that doesn't fit in one cell (123 bytes after the op code, 127 bytes per further cell) continues in a chain of references ("snake" format).

Encrypted comments use op 0x2167da4b. They can only be decrypted with the wallet's private key, which this tool doesn't do.
