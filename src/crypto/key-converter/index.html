🔄 Key Converter

Convert keys between PEM, DER, JWK and raw bytes.

What it reads

PEM: PKCS#8 “PRIVATE KEY”, SPKI “PUBLIC KEY”, SEC1 “EC PRIVATE KEY”, PKCS#1 “RSA PRIVATE KEY” / “RSA PUBLIC KEY”. Also JWK (or a JWKS — the first key is used), OpenSSH public keys (ssh-ed25519, ssh-rsa, ecdsa-sha2-nistp256/384), the same structures as DER in hex or base64, and raw key bytes for Ed25519, X25519 and the EC curves (choose the type above). The public key is derived from a private key. Encrypted keys and OpenSSH private keys aren’t supported; decrypt or convert them first.
